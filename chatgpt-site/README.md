# EcoSignal CI — export de la présentation ChatGPT Sites

Ce dossier contient une copie statique autonome de la page publique :

- Site en ligne : https://ecosignal-ci.kouassy01108550.chatgpt.site/
- Titre : `EcoSignal CI — Signaler. Suivre. Agir.`
- Export réalisé le 2 septembre 2026.

## Hébergement actuel

La présentation est publiée avec **ChatGPT Sites** sur un domaine `chatgpt.site`. Le déploiement Sites s'exécute sur l'infrastructure de publication gérée par OpenAI, fondée sur Cloudflare Workers.

## Contenu de ce dossier

- `index.html` : copie statique autonome de la page d'accueil, avec les styles intégrés ;
- `README.md` : informations sur l'origine, l'hébergement et l'utilisation de l'export.

Ouvrez simplement `index.html` dans un navigateur pour consulter cette présentation hors ligne.

## Différence avec l'application principale

Cet export correspond à la **présentation/démonstration créée avec ChatGPT Sites**. Il ne remplace pas l'application principale déjà présente à la racine du dépôt :

- frontend React ;
- API Laravel ;
- base de données PostgreSQL/MySQL selon l'environnement ;
- gestion des rôles Citoyen, Agent et Administrateur.

L'export est donc conservé dans un dossier séparé afin de ne pas écraser le projet applicatif existant.
